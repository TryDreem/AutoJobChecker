# AutoChecker

**AutoChecker** — Telegram-бот, который собирает вакансии и фриланс-заказы из
Telegram-каналов, job boards и RSS, убирает шум, склеивает дубли и присылает
только релевантные карточки.

Проект решает типичную проблему поиска работы: хорошие объявления тонут среди
курсов, резюме, нерелевантных стеков, повторов и устаревших постов. AutoChecker
превращает поток источников в короткую ленту с оценкой, зарплатой, стеком,
форматом работы, контактами и ссылкой на оригинал.

## Что умеет

- **Собирает вакансии из нескольких каналов сразу.** Telegram-каналы, RemoteOK,
  Remotive, Arbeitnow, Jobicy, Himalayas, RSS-ленты и опциональный Upwork через
  официальный API.
- **Фильтрует не по ключевым словам, а по смыслу.** Бот извлекает грейд, стек,
  формат работы, географию, зарплату, контакты и тип поста.
- **Отсекает мусор до уведомлений.** Курсы, резюме, крипта, нерелевантные роли
  и слабые посты не попадают в личку.
- **Склеивает дубли.** Одна и та же вакансия из нескольких каналов приходит
  один раз.
- **Объясняет оценку.** У каждой карточки есть полный текст и причины, из чего
  сложился скоринг.
- **Работает без платных сервисов.** LLM-классификация через Groq опциональна:
  без ключа остаётся полностью рабочий rule-based пайплайн.
- **Настраивается из Telegram.** Стек, грейд, формат, ключевые и стоп-слова
  меняются кнопками, без правки кода.

## Кому полезен

- разработчикам, которые мониторят много Telegram-каналов и job boards;
- junior/middle специалистам, которым важно быстро находить подходящие позиции;
- фрилансерам, которые хотят ловить заказы раньше, чем они потеряются в потоке;
- тем, кто ведёт персональный job radar и хочет контролировать источники,
  фильтры и историю откликов у себя.

## Быстрый старт

```bash
python3.11 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env
# Заполни BOT_TOKEN, ADMIN_IDS и при необходимости Telegram MTProto ключи.

python -m app.tools.login      # один раз, если нужны Telegram-каналы
python -m app.tools.selfcheck  # проверка конфигурации
python main.py
```

Без `TG_API_ID` и `TG_API_HASH` бот не читает Telegram-каналы, но источники с
открытыми API и RSS продолжают работать. Без `GROQ_API_KEY` классификация идёт
по локальным правилам.

## Переменные окружения

| Переменная | Назначение | Обязательна |
|---|---|---|
| `BOT_TOKEN` | токен Telegram-бота из `@BotFather` | да |
| `ADMIN_IDS` | Telegram user id владельцев бота через запятую | да |
| `TG_API_ID`, `TG_API_HASH` | ключи аккаунта-парсера с `my.telegram.org` | для Telegram-каналов |
| `TG_PHONE` | телефон аккаунта для первичного входа через Telethon | для файловой сессии |
| `TG_SESSION_STRING` | готовая строка Telethon StringSession | альтернатива файловой сессии |
| `GROQ_API_KEY` | LLM-классификатор спорных постов | нет |
| `UPWORK_CLIENT_ID`, `UPWORK_CLIENT_SECRET`, `UPWORK_REFRESH_TOKEN` | Upwork API | для Upwork |

## Безопасность

Репозиторий рассчитан на публичную публикацию без приватных данных:

- реальные ключи лежат только в `.env`;
- `.env`, `.env.*`, `data/`, базы, логи, `.session`, `.venv` и IDE-файлы
  добавлены в `.gitignore`;
- `.env.example` содержит только пустые поля и безопасные дефолты;
- Telegram session file и `TG_SESSION_STRING` считаются секретами, потому что
  дают доступ к аккаунту-парсеру.

Перед публикацией нового форка проверь:

```bash
git status --ignored --short
git ls-files
```

В списке отслеживаемых файлов не должно быть `.env`, `data/`, `.session`,
баз данных, логов или локальных IDE-настроек.

## Как это работает

1. **Сбор.** Планировщик регулярно опрашивает Telegram, job boards и RSS.
2. **Извлечение фактов.** Пайплайн достаёт зарплату, стек, роль, грейд, формат,
   географию, контакты и метаданные источника.
3. **Скоринг.** Rule-based модель выставляет оценку 0-100 с объяснением каждого
   слагаемого.
4. **Дедупликация.** Точный хеш ловит копипасту, simhash на 3-граммах ловит
   перепечатки с небольшими правками.
5. **LLM для спорных случаев.** Если включён Groq, пограничные посты
   классифицируются пачками, чтобы не тратить лимит на очевидные случаи.
6. **Уведомления.** Подходящие посты приходят в Telegram карточками с действиями.

## Управление в боте

| Раздел | Что внутри |
|---|---|
| Лента | свежие релевантные вакансии и заказы |
| Избранное | сохранённые карточки |
| Поиск | поиск по всей базе, включая скрытые посты |
| Фильтры | стек, грейд, формат, оплата, ключевые и стоп-слова |
| Источники | включение, проверка и добавление источников |
| Статистика | качество источников и объём собранных данных |
| Сводка за день | компактный дневной дайджест |

Под карточкой доступны действия: открыть оригинал, добавить в избранное,
скрыть, посмотреть полный текст, отметить отклик.

## Источники

Готовые источники лежат в `config/sources.yaml`.

- Telegram-каналы можно проверять и дополнять прямо из бота.
- Job boards с открытыми API работают без ключей.
- RSS-ленту можно добавить без кода.
- Upwork выключен по умолчанию и включается после настройки API-ключей.

## Архитектура

```text
main.py                     запуск бота и планировщика
config/sources.yaml         стартовый каталог источников
app/
├── config.py               настройки из .env
├── scheduler.py            фоновые задачи
├── core/                   модели, БД, схемы
├── sources/                Telegram, job boards, RSS, Upwork
├── pipeline/               извлечение фактов, скоринг, LLM, дедупликация
├── bot/                    aiogram 3: хендлеры, клавиатуры, карточки
└── tools/                  login, selfcheck, reclassify, upwork_login
```

## Добавление нового источника

Если у площадки есть RSS, достаточно добавить URL в `config/sources.yaml`.
Для кастомного источника нужен класс, который отдаёт `RawPost`:

```python
from app.sources.base import BaseSource, RawPost
from app.sources.registry import register


@register("mysite")
class MySiteSource(BaseSource):
    display_name = "My Site"

    async def fetch(self, since):
        for item in await self._load():
            yield RawPost(
                external_id=item.id,
                text=item.text,
                posted_at=item.posted_at,
            )
```

После этого источник добавляется в `config/sources.yaml` и автоматически
попадает в общий пайплайн.

## Настройка под себя

- словари технологий, географии и маркеров мусора: `app/pipeline/keywords.py`;
- веса скоринга: `app/pipeline/scoring.py`;
- расписание обхода: `.env`;
- источники: `config/sources.yaml`;
- пользовательские ключевые и стоп-слова: через Telegram-бота.

## Диагностика

```bash
python -m app.tools.selfcheck
```

| Симптом | Что проверить |
|---|---|
| Бот не отвечает | `BOT_TOKEN`, `ADMIN_IDS` |
| Telegram-каналы не читаются | `TG_API_ID`, `TG_API_HASH`, `python -m app.tools.login` |
| Лента пустая | выполнить `/scan`, снизить порог релевантности, проверить источники |
| Много дублей | запустить переоценку через `app.tools.reclassify` |
| LLM не используется | `GROQ_API_KEY`, `LLM_ENABLED`, дневной лимит |
